Why Sweep?

A true story that every developer experiences eventually.

It started during a routine mobile development sprint. A build failed abruptly with a "Not enough space" error. While the target iPhone had plenty of storage, a check on the host development machine revealed a shocking truth: only 1 GB of free disk space remained.

Over years of programming, hidden files like Xcode's DerivedData, deep Android emulator logs, and hundreds of nested node_modules folders had quietly suffocated the machine. Finding and purging these manual system directories was painful and error-prone.

That's why Sweep was born. Built as a collaborative pair-programming project with Google Gemini (Antigravity), it is a high-performance command center to detect, review, and wipe out these silent space eaters instantly, giving your workstation room to breathe.

Features Designed for Developers

Sweep knows exactly where storage hogs hide and allows you to reclaim them safely.

📱

Mobile Caches

Deep-clean Xcode DerivedData build archives, Android Studio emulators/AVD, and Flutter build layers taking up gigabytes of space.

🌐

Web Bloat Cleaner

Quickly find orphaned node_modules in old projects, wipe PNPM store caches, and clear Next.js production build artifacts.

⚙️

Systems & Compilers

Prune bloated Rust Cargo target folders, clear Python Conda environment caches, and purge unused Docker image layers.

🛡️

Review Before Purging

Safety is paramount. Sweep gives you a checklist of every discovered folder so you can review their sizes before confirming deletion.

⚡

Built with Rust

The Tauri v2 backend runs file system crawlers natively in Rust, achieving rapid disk scanning in seconds with near-zero memory footprint.

🔮

Glassmorphism UI

A premium, dark-mode terminal-inspired layout that fits your developer environment, featuring live metrics of CPU, RAM, and storage.

Frequently Asked Questions

Everything you need to know about Sweep, security, and project status.

Is Sweep safe to use? Will it delete important source files?
Sweep is highly safe. It never deletes files automatically. It performs a read-only crawl across your paths and displays all identified target directories. You can review them, select or deselect specific items, and confirm only the paths you wish to delete.
Why should I use Sweep instead of a custom terminal cleanup script?
Terminal scripts lack selective visual confirmation and can be dangerous if a wildcard is misapplied. Sweep features a gorgeous glassmorphic GUI that displays visual metrics, lets you scan nested workspaces recursively, and shows immediate disk savings before executing any operations.
How do I install and run Sweep on Windows or Linux?
You can compile Sweep yourself by cloning the repository and running `pnpm install` followed by `cargo tauri dev`. We are actively compiling pre-packaged binaries for Windows (.msi) and Linux (.deb), and we welcome developer testing on these packages.
How was Sweep developed?
Sweep was pair-programmed between a human developer and Google Gemini (Antigravity) by DeepMind, leveraging AI to quickly build high-performance Rust integrations and modern UI components.
